## Methods

### isAvailable()

Available when a provider is already here, or when a hosted wallet is configured — the hosted build needs no install, so it is always usable. Deliberately does NOT wait for the hosted script: this answer gates a modal, and a wallet that takes a network round trip to say "yes" reads as broken. The script is fetched on the first real call instead.

```ts
isAvailable(): Promise<boolean>
```

**Returns** `Promise<boolean>`
