A USDT0 transfer from Stellar to an EVM network through LayerZero, from `client.usdt0`. Non-custodial like a &#123;@link Swap&#125;: the API builds one Soroban transaction (&#123;@link xdr&#125;, or the SEP-7 &#123;@link uri&#125;), the account that holds the USDT0 (&#123;@link source&#125;) signs it, and `await transfer.submit({ signedXdr })` relays it. LayerZero then delivers it (about 27 minutes on every route); follow it with `await transfer.fetch()` until &#123;@link isFinal&#125;.
