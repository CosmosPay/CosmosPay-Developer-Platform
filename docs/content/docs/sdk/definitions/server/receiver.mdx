A verified identity — the thing both ramps hang off. Everything a receiver owns is reachable from the instance (`receiver.addBankAccount(…)`, `receiver.wallets()`), because the alternative is carrying a receiver id and a manager reference side by side through a KYC flow that already has enough moving parts.
