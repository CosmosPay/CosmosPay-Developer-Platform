Fiat → stablecoin — `client.onramp`. Three steps, in this order and no other: **quote** (a price, valid for about five minutes), **payin** (created FROM that quote, and what returns the funding instructions the payer acts on), then the money arrives off-band and the payin status moves on its own. There is no structure class here on purpose. A payin has no action of its own — it is a mirror of the provider's record, read and re-read — so an object with a client back-reference would carry a `fetch()` and nothing else.

### createTrustline()

Build the unsigned trustline transaction an address needs before it can hold the stablecoin the ramp pays out in. The envelope comes from the gateway, so a wallet signing it must decode and bound it first — the issuer it names is the one the payout will use, and it is not known to the caller in advance.

```ts

```

**Parameters**

**Returns** `Promise<TrustlineData>`
