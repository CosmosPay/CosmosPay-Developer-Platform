DeFindex vaults on Stellar — `client.defindex`. Served only where the deployment enables the DeFindex native plugin (`PLUGINS_ENABLED=defindex`); elsewhere every call is a 404. The payloads are DeFindex's own and are passed through untyped. Deposits and withdrawals come back as an unsigned transaction for the caller to sign and hand to &#123;@link submit&#125;.
