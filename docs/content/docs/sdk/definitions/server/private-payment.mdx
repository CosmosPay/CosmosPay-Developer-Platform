A private payment, from `client.privatePayments`: an amount in XLM whose value is hidden on-chain. The payer pays it with confidential transfers on Cosmos Pay's confidential token (net to &#123;@link recipient&#125;, the commission to &#123;@link feeAccount&#125;, and a third one when there is a &#123;@link merchantFee&#125;) and confirms them through the private checkout. Poll with `await payment.fetch()`.
