          Requires the `kyc:read` scope.
        heading: list-a-receivers-wallets
      - content: >-
          Registers the wallet at BlindPay under the receiver and mirrors it
          locally. Send `address` (account abstraction or the non-secure flow),
          or the `signature_tx_hash` of the message from `GET
          /v1/kyc/receivers/{receiverId}/wallets/sign-message` (secure EOA
          flow). `network` is one of BlindPay's: Stellar, Solana, Tron,
          Ethereum, Base, Arbitrum, Polygon or one of their test networks. A
          disabled receiver is refused with 403 `account_disabled`.


          Requires the `kyc:write` scope.
        heading: register-a-blockchain-wallet-for-a-receiver
      - content: >-
          Deletes the wallet at BlindPay, then its local row. A wallet id this
          receiver does not have answers `deleted: true` without calling
          BlindPay, so repeating a delete succeeds.


          Requires the `kyc:write` scope.
        heading: delete-a-wallet
      - content: >-
          Reads the local mirror, newest first; BlindPay is not called, and
          account numbers are never returned. Paginated with `take` (default
          100, max 100) and `skip`; answers `{ data, total, take, skip }`.


          Requires the `kyc:read` scope.
        heading: list-a-receivers-bank-accounts
      - content: >-
          Creates the account at BlindPay under the receiver and mirrors it;
          offramp payouts settle to it. `type` names the rail, and only that
          rail's fields are needed (`GET /v1/kyc/bank-details?rail=` lists
          them). The response carries identifiers only (`rail`, `name`,
          `country`), never the account numbers. A disabled receiver is refused
          with 403 `account_disabled`.


          Requires the `kyc:write` scope.
        heading: add-a-fiat-bank-account-for-a-receiver

          Requires the `kyc:write` scope.

          Relays BlindPay's catalog of bank rails on the instance of the key's

          is stored; the body is BlindPay's answer as returned.


          Requires the `kyc:read` scope.
        heading: list-available-bank-rails
